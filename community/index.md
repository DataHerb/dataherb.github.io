- **Questions and bugs:** open an issue on [dataherb-explorer](https://github.com/DataHerb/dataherb-explorer/issues) for the site and catalog, or on [dataherb-python](https://github.com/DataHerb/dataherb-python/issues) for the CLI.
- **Contributions:** pull requests are welcome on both repositories, from typo fixes to new store types.
- **Open datasets:** propose a dataset for the public catalog with a pull request adding `catalog/<id>.md` to the explorer.
- **Chat:** the [DataHerb Telegram channel](https://t.me/dataherb) is where datasets used to be shared.
