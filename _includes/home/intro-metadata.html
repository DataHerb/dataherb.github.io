A searchable catalog, built from metadata.
  • Each dataset is described by a dataherb.yml next to its files, in a git repository, an S3 prefix, a web folder or the catalog repo itself.
  • The catalog lists datasets as small Markdown files with YAML front matter. The body is free Markdown shown on the dataset page.
  • Facets for tags, domain, owner, freshness, storage and format, plus schemas, documentation, copy-paste snippets and a metadata quality score.
Explore data in the browser.
  • DuckDB-WASM previews and profiles CSV, Parquet and JSON files without a server.
  • Write SQL across datasets, build joins with a helper, and draw bar, line, scatter and histogram charts.
  • Summary statistics, correlations and shareable links that capture the query.
