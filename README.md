# dataherb.github.io

The DataHerb website, built with Jekyll and served at https://dataherb.github.io.

DataHerb v2 is [DataHerb Explorer](https://github.com/DataHerb/dataherb-explorer), a static, forkable data catalog and explorer ([live demo](https://dataherb.github.io/dataherb-explorer/)), with the `dataherb` CLI from [dataherb-python](https://github.com/DataHerb/dataherb-python). The v1 Flora pages (`_flora/`, `flora/`) are kept for reference.
